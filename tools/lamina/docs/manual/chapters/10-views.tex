\chapter{Views and panels}\label{ch:views}
\begin{goals}
\textbf{In this chapter} you will hold several files, and several views of one file, side by side in
tabs and splits.
\end{goals}

\begin{pending}
This chapter waits on documents, views and panels, which are being built (the workspace plan,
\file{spec\_inbox/lamina-workspace-spec.md}, §§1–2 and 5). It will cover:
\begin{itemize}
\item \textbf{Documents and views}: a document is a file, its index and its caches; a view is a filter,
a sort, calculated columns and formats over it. A file can have several views, which share its index.
\item \textbf{Tabs and splits}: arranging panels; dragging a tab into a split; floating one.
\item \textbf{Several files}: opening and dropping more than one; each file a tab.
\item \textbf{Workbooks and archives}: every sheet a tab; archive members opened on demand from a list.
\item \textbf{New view of this file}: the same file twice, with two filters (ore beside waste).
\item \textbf{The focused panel}: the menus and tools act on it; the status line follows it; the columns
panel and the record inspector as panels of their own.
\item \textbf{Panels don't talk to each other}: no shared filter, no instrument over two views.
\item \textbf{Memory}: a file not on screen gives up its caches and keeps its index.
\item \textbf{Narrow screens and the Android shell}: tabs only.
\end{itemize}
\end{pending}
