## How it was made (and how to keep it true)
Drafted by chapter, every claim run on the built page; then an accuracy review by three fresh readers
(~700 claims), a line edit (micro's STYLE.md), references checked against Crossref, and a typesetting read
of every page. Each round found bugs in wuffle itself, fixed in code and covered by tests (see the git log
from 2026-11-26). When wuffle changes: re-run `node build.mjs` (screenshots can't go stale), and re-run the
probes for any chapter whose feature changed.
